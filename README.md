# 🎬 Flow Video Production Doctrine & Pre-Flight SOP
> **คัมภีร์กฎเหล็กและมาตรฐานการผลิตวิดีโอ Google Flow (Veo 3.1 / Omni) & Reels Affiliate สำหรับ Autonomous Agents**  
> *Single Source of Truth ประจำทีมงาน เจ้านาย (NN) และพนักงาน AI ทุกตัว*

---

## 🧭 วัตถุประสงค์ของคัมภีร์นี้ (Purpose)
เอกสารนี้คือ **"ธรรมนูญสูงสุด"** ในการผลิตสื่อวิดีโอสั้น Facebook Reels และ Shopee Video ป้ายยา Affiliate  
**กฎข้อที่ 0:** ไม่ว่า Agent ตัวไหน หรือใครจะเขียนสคริปต์ผลิตวิดีโอ **ต้องอ่านและยึดถือเอกสารนี้ก่อนเริ่มเขียนหรือรันสคริปต์เสมอ ห้ามคิดสด ห้ามข้ามขั้นตอน และห้ามใช้นอกเหนือจากที่ระบุในนี้เด็ดขาด!**

---

## 🚨 กฎเหล็ก 7 ประการ (The 7 Inviolable Commandments)

### 1. 🖼️ โหมดวิดีโอสำหรับ Storyboard Grid & Veo 3.1 - Lite [Lower Priority]
* **ชื่อโมเดลเต็มที่ถูกต้อง:** **`Veo 3.1 - Lite [Lower Priority]`** (`veo_3_1_r2v_lite`)
* **คุณสมบัติหลัก:**
  * ความยาวคลิป: **8 วินาที (8s)** (หรือ 8s+8s = 16s Concat ด้วย Last-Frame Seeding)
  * ต้นทุนเครดิต: **0 เครดิต (ฟรี 100% บนบัญชี ULTRA ไม่เสียแต้มเลยสักบาทเดียว!)**
  * โหมดที่ใช้: **`Ingredients to Video` (หรือในระบบคือโหมด "องค์ประกอบ" / `mode: "r2v"`)**
  * การแนบภาพ: **เก่งเรื่องการนำภาพ Master 2x2 Storyboard Grid ไปสร้างวิดีโอ** โดยส่ง `referenceMediaIds: [grid_media_id]` AI จะอ่านลำดับช็อตทั้ง 4 ช่องบน Grid มาสร้างวิดีโอเดินเรื่องต่อเนื่องได้อย่างแม่นยำ
* **โมเดลทางเลือกพรีเมียม (Omni):** `Omni 1.1 Flash` (`abra_r2v_10s`) ความยาว 10s (ใช้ 30 เครดิต) สำหรับคลิปเน้นตัดต่อฉาก A/B-Roll พิเศษที่เจ้านายสั่งใช้งานเฉพาะกิจ

---

### 2. 💰 ตารางคุมเครดิต & สองโหมดการผลิต (Dual Production Strategy)
เราแบ่งการผลิตออกเป็น **2 โหมดชัดเจน** ตามวัตถุประสงค์ของเจ้านาย:

| โหมดการผลิต | Engine Model (API Key) | Mode Flow | ความยาว | เครดิต (ULTRA) | วัตถุประสงค์ & สไตล์ |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **★ Veo 3.1 - Lite [Lower Priority]** | `veo_3_1_r2v_lite` | **Ingredients to Video (`r2v`)** แนบภาพ Master 2x2 Grid | **8s** (หรือ 8s+8s = 16s Concat) | **0 เครดิต (ฟรี 100%!)** | **โหมดหลักปั๊มสต็อกจำนวนมาก!** เก่งเรื่องการนำภาพ 2x2 Grid มาสร้างวิดีโอพาเดินชมสวนสีเขียวและทางเดิน ต้นทุน 0 บาท ปั๊มได้ไม่อั้น |
| **★ Omni 1.1 Flash (พรีเมียม)** | `abra_r2v_10s` | **Ingredients to Video (`r2v`)** แนบภาพ Master 2x2 Grid | **10s** (หรือ 10s+10s = 20s Concat) | 30 cr | **งานตัดต่อพรีเมียมที่เจ้านายชอบ!** สลับฉากตัดต่อ A/B-Roll ตาม Grid ชัดเจน เหมาะกับสินค้า Winner ตัวชูโรง |
| ❌ **โมเดลต้องห้าม** | `veo_3_1_i2v_s_fast_ultra` | Image-to-Video | 8s | **เสียเครดิตสูง** | **ห้ามใช้เด็ดขาด!** (เป็นจุดที่ทำเครดิตรั่วไหล) |
| ❌ **โมเดลต้องห้าม** | `veo_3_1_t2v` | Text-to-Video | 8s | **100 cr** | **ห้ามใช้เด็ดขาด!** |

> ⚠️ **คำเตือนเครดิต:** ในการทำสูตร 8s + 8s = 16s ประหยัดเครดิต หากจะใช้สูตร 0 เครดิต ห้ามส่ง `modelKey: "veo_3_1_i2v_s_fast_ultra"` ใน Cut 2 เด็ดขาด!

### 3. 📸 รูปสินค้าจริง (Product Image Injection)
* **การดึงสินค้า:** ต้องดึงรูปสินค้าจริงจาก Shopee Feed ที่มียอดขายจริง คะแนน 4.8 - 5.0 ดาว
* **ช่วงราคาแนะนำ:**
  * **50 – 400 บาท:** สินค้าซื้อง่าย ดึงดูดคนดู ดูแล้วสั่งทันที (แผ่นปูพื้น, สีสเปรย์, ผ้าใบกันสาด, สแลน, ถุงปลูก)
  * **ต่ำกว่า 50 บาท:** **ตัดทิ้งทันที** (ราคาถูกเกินไป ไม่คุ้มค่าคอม)
  * **1,000 – 2,000 บาท:** สินค้า High-Ticket ตะกร้าใหญ่ (กรงไก่ประกอบเอง, ปั๊มน้ำโซล่าเซลล์)
* **การโชว์สินค้าในคลิป:** ต้องเห็นตัวกระป๋อง, กล่อง, หรือแพ็กเกจจิ้งของสินค้าจริงในช่องที่ 1 และ 2 ของ Grid เสมอ

---

### 4. 🌿 มุมกล้องและการเคลื่อนไหว (Vlog Tour / POV Doctrine)
* **สไตล์หลัก:** **First-Person POV เดินชมบรรยากาศสีเขียวสดใส (Green Garden Walk-Through)**
* **ระยะกล้อง:** **Medium to Wide Shot (ระยะหน้าอก/ระดับสายตา)** ห้ามซูม Extreme Macro ใกล้เกินไป เพราะ AI เจนรายละเอียดและนิ้วมือเพี้ยน
* **Empty Hands 100%:** มือเปล่า ไม่ถือโทรศัพท์มือถือ ห้ามมีหน้าจอมือถือโผล่เข้ามาในเฟรมเด็ดขาด
* **Restrained Hand Motion:** ไม่ผายมือหรือโบกมือสะเปะสะปะตลอดเวลา ให้มุมกล้องแพลน (Pan & Tilt) เป็นตัวนำ และยื่นมือแตะ/ชี้สินค้าเบาๆ เพียง 1–2 ครั้งสั้นๆ แล้วลดมือลง

---

### 5. 🎙️ ระบบเสียงพากย์ (Orus TTS Doctrine)
* **โมเดล:** `google/gemini-3.1-flash-tts-preview` เสียง **Orus** ผ่าน OpenRouter API เท่านั้น
* **ข้อห้ามสคริปต์:**
  * ❌ **ห้ามพูดคำว่า "100%" (หรือ "ร้อยเปอร์เซ็นต์") เด็ดขาด!** ให้ใช้คำว่า *"สบายหายห่วง"*, *"มั่นใจได้เลย"* แทน
  * ❌ **ห้ามพูดตัวเลขราคาเด็ดขาด** (เพราะราคาบน Shopee มีการเปลี่ยนแปลงตลอดเวลา)
  * ❌ มีคำว่า **"ครับ"** ได้สูงสุด **1 ครั้งที่ท้ายคลิปเท่านั้น**
* **Audio Engineering:**
  * สแกนตัด Dead Silence ทิ้ง + Overlap 80ms ระดับเสียง +1.25dB
  * ผสม Flow ASMR Ambient Bed เบาๆ ที่ระดับ -15dB ถึง -16dB

---

### 6. 💬 ซับไตเติลภาษาไทย (Boss Standard Subtitles)
* **ขนาด & สไตล์:** ฟอนต์ตัวหนาขนาด **68pt** สีขาวสว่าง (`#FFFFFF`) ขอบสีดำหนาคมชัด (`#000000`, Outline = 5.0) **ปิดเงาสนิท (Shadow = 0)**
* **Safe Zone:** วางที่ตำแหน่ง **30% จากขอบล่างของหน้าจอ (`MarginV: 384` บนเฟรม 720x1280)** เพื่อหลบ UI ของ TikTok และ Reels
* **การแบ่งท่อน (Word Chunking):**
  * **ถอดตรงจากบทพูด TTS จริงของแต่ละคลิป 100%** ห้ามใช้คำซ้ำข้ามคลิป
  * หั่นเป็นคำสั้นกระชับ **2–3 คำต่อท่อน** ป๊อปเด้งตามจังหวะเสียงพูดจริง

---

### 7. 🚀 การโพสต์และปกป้อง Organic Reach
* **ห้ามใช้ Meta Graph API ในการโพสต์เด็ดขาด** (ต้องนำคลิปไปผ่าน CapCut ล้าง metadata แล้วโพสต์มือผ่านแอป Facebook บนมือถือ/iPad เพื่อให้ได้ Organic Reach สูงสุด)
* **แคปชั่น:** **ห้ามใส่ลิงก์เด็ดขาด!** ใส่ได้เฉพาะเนื้อหาป้ายยาและแฮชแท็ก
* **ลิงก์สินค้า:** แปะ Shortlink Shopee ส้มสมหวัง (`affiliate_id: 15361420425`) ใน **คอมเมนต์แรกเท่านั้น**

## 🛠️ โครงสร้างขั้นตอนการผลิตที่ถูกต้อง (The Certified Pipeline)

```
[ 1. คัดเลือกสินค้าจาก Shopee Feed (50-400฿) ]
                      ↓
[ 2. ดาวน์โหลดรูปสินค้าจริง (.jpg) ]
                      ↓
[ 3. Upload Image เข้า Flow API ] ──> ได้ product_media_id
                      ↓
[ 4. สร้าง Master 2x2 Storyboard Grid (4 ช่องแนวตั้ง 9:16) ]
     - Model: NARWHAL (Aspect: PORTRAIT)
     - References: [product_media_id]
     - ผลลัพธ์ ──> ได้ grid_media_id
                      ↓
[ 5. สร้างวิดีโอด้วยโหมด Ingredients to Video (R2V) ] ★ จุดสำคัญ ★
     - Mode: "r2v" (องค์ประกอบ)
     - ReferenceMediaIds: [product_media_id, grid_media_id]  <-- แนบ 2 รูป!
     - Model: abra_r2v_10s (Omni) หรือตามที่กำหนด
                      ↓
[ 6. สังเคราะห์เสียง Orus TTS (Gemini 3.1 Flash) ]
     - ตัด Dead Silence + Overlap 80ms
     - Mix รวมกับ Flow ASMR Ambient Bed (-15dB)
                      ↓
[ 7. ฝังซับไตเติลภาษาไทย 68pt ที่ 30% จากขอบล่าง ]
     - หั่นสคริปต์ 2-3 คำ ป๊อปเด้งตรงตามเสียงจริง
                      ↓
[ 8. ลงทะเบียนคลังสต็อกแดชบอร์ด SQLite (fb_video_stock) ]
     - บันทึกคลิปพร้อมแคปชั่นและคอมเมนต์พิกัด
```

## 🛡️ Pre-Flight Verification Script (`preflight_guard.py`)
สคริปต์ Python ใน Repo นี้สามารถถูก import ไปใช้ในตัวรันทุกตัว เพื่อตรวจสอบความปลอดภัยก่อนส่งคำสั่งเข้า API หากพบการตั้งค่าผิดกฎ (เช่น มีภาพ Grid แต่ไม่ใช้โหมด r2v หรือใช้โมเดลกินเครดิตโดยไม่ได้รับอนุญาต) โปรแกรมจะยกเลิกการรันทันที
